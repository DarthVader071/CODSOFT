Codsoft_1.py :
  This python program is for the to-do list python program and can add, update and delete tasks.
Codsoft_2.py :
  This python program is to display a gui-based simple arithmetic calculator that can add, subtract, multiply, and divide
Codsoft_3.py:
  This python program is to generate a random password that is generated under the given digits constraints given through the input box in the gui interface

All the above programs are gui-based (or more precisely done with tkinter python module) python programs
Also the task.txt file is generated automatically (within the same directory as the python file) to store the password generated in the system solidly.
